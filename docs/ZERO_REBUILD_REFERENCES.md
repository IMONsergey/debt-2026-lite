# DEBT TECH 2026 — zero rebuild reference logic

This experimental branch intentionally preserves only content, block sequence and the DEBT TECH logo.

Reference principles used:
- Karman Project: chapter-based storytelling, persistent navigation, giant typography crossing media.
- Edolus: one dominant planetary object and restrained information hierarchy.
- Portal Space Systems: black negative space, asymmetric hero object, engineering restraint.
- Oakley × Axiom: full-bleed cinematic media and product-grade information overlays.
- Wix Space: scroll-led perspective changes and oversized editorial typography.
- Nike Infinite Space: product/content embedded into an immersive space context rather than placed on decorative cards.
- Omega Space Sustainability: Earth as a narrative/data surface, minimal interface over a spatial scene.
- Noomo Showcase: camera/scene progression tied to scroll; motion is structural rather than ornamental.

Implementation is original. No proprietary source code or protected media from the reference sites is copied into this repository.
The Three.js Earth texture is sourced from the Three.js example assets (NASA-origin imagery) for this experimental prototype.

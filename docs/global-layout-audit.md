## Проверки

`npm run check` запускает:

1. Тесты скидок и формы. Отправка проверяется через подставной ответ; реальные заявки не создаются.
2. Проверку 75 ссылок на ассеты: данные сайта, все кадры галереи, тарифы, иконки и шрифты.
3. Production build.
4. 3232 статические проверки каскада и геометрии: 28 ширин от 320 до 1920 px × 4 высоты.

Статическая проверка **не заменяет рендеринг**. Она проверяет конкретные правила сеток, кнопки и границы переключений, но не доказывает отсутствие любых пересечений текста.

В опубликованном превью при 1363×936 проверены герой, тарифы, организатор, корпоративный блок, контакты, переключение галереи и фотодиалог. Формы открываются, выбранный тариф и цена передаются, Tab/Shift+Tab остаются внутри окна, Escape закрывает его и возвращает фокус. Шрифты загрузились, сломанных изображений и горизонтального переполнения страницы не обнаружено. В просмотренных записях консоли ошибок приложения нет; сообщения расширения браузера исключены.

Мобильная эмуляция в доступном браузере отсутствует. Перед основным релизом остаются визуальные проверки на реальных телефонах, планшетах и в Safari. Доставка в Telegram/CRM не проверяется, чтобы не отправлять тестовые заявки организаторам.

## Структура для дальнейшей работы

- `src/data/content.js` — тексты, тарифы, ссылки и изображения.
- `src/components/*Section.jsx` — независимые секции.
- `src/styles/global.css` — шрифты, переменные, каркас.
- `hero.css`, `fixed-menu.css`, `gallery.css`, `application-modal.css` — вместо смешанных слоёв `hero-only*` и `site-fidelity`.
- `src/styles/ui.css` — общие CTA; положение кнопок остаётся в стилях секций.
- `src/hooks` — таймер, фокус диалога, пересчёт каруселей.
- `src/lib/forms.js` — контракт отправки. Backend `server/forms-telegram.mjs` не переписан.

1180/1181 px переключает боковую панель и адаптивный герой. Организатор: одна колонка до 639 px, две до 1180 px, три выше. Корпоративный блок использует container queries по своей фактической ширине.
